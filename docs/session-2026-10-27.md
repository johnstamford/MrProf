## Lessons learned
- **Rebuild after every backend edit.** The api image bakes code at build time; `pytest` runs
  stale code otherwise. Bitten 3×. Fast path: `docker compose cp` single files for iteration,
  full `build` before trusting results.
- **Suite must force dummy.** Container env carries the live key, so `conftest.py` pins
  `LLM_PROVIDER=dummy`; live coverage is opt-in only (`MRPROF_LIVE_SMOKE=1`, `sim/run.py --live`).
- **CLI can't change server config.** Provider/model is server-side only; sim CLI chooses patient
  kind, never the interviewer. Enforced structurally (fixed payload keys), not by convention.
- **Dedupe before numbering.** Re-segmented transcript questions consumed line numbers —
  discard already-stored segments before assigning new lines (fixed, tested).
- **Refactors need immediate build+test.** An orphaned duplicate function body slipped in during
  an edit; the suite caught it. Never stack edits without running tests between.
- **Transient model failures are normal.** Interviewer retries once on timeout/provider blip;
  interview UI shows the backend's error + Try again. Logs rotate away on rebuild — check promptly.
- **Data hygiene:** clean fixtures after every live verification; never touch user-owned records;
  `sim/runs/`, `.env`, and local DB contents stay out of git.
